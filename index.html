Что такое JavaScript?

JavaScript — это высокоуровневый интерпретируемый язык программирования, стандартизированный по спецификации ECMAScript. Изначально созданный Бренданом Айком в 1995 году для браузера Netscape, сегодня он работает везде: в браузерах, на серверах (Node.js), в мобильных приложениях, десктопе и даже в микроконтроллерах.

Ключевые возможности

JavaScript — мультипарадигменный язык. Он поддерживает функциональный, объектно-ориентированный и событийный стили программирования.

  • Асинхронность: Promise, async/await
  • Функции первого класса и замыкания
  • Работа в браузере и на сервере
  • Огромная экосистема npm
  • Событийно-ориентированная модель
  • Кроссплатформенность

От динамической типизации до прототипного наследования — JS даёт гибкость, которая одновременно является его силой и слабостью.

Асинхронность

Современный способ работы с асинхронным кодом через async/await. Читается как синхронный, работает как асинхронный.

async function fetchUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error('Ошибка сети');
    const user = await res.json();
    return user;
  } catch (err) {
    console.error('Не удалось загрузить:', err);
  }
}

Массивы и методы

Цепочки методов map, filter, reduce — сердце функционального стиля в JS.

const users = [
  { name: 'Аня', age: 25, active: true },
  { name: 'Борис', age: 17, active: false },
  { name: 'Вика', age: 30, active: true }
];

const adultNames = users
  .filter(u => u.active && u.age >= 18)
  .map(u => u.name.toUpperCase())
  .join(', ');

console.log(adultNames); // "АНЯ, ВИКА"

Замыкания

Функция «запоминает» своё лексическое окружение — основа для модулей, счётчиков и приватных переменных.

function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    value: () => count
  };
}

const counter = createCounter();
counter.increment();
counter.increment();
console.log(counter.value()); // 2
